Glimpse 首个完整离线 Windows x64 安装预览版。

下载本页 `Glimpse-0.1.0-preview.1-win-x64-offline-setup.exe` 和全部同名前缀的 `.bin` 文件，放在同一文件夹后运行 `.exe`。无需合并分卷。`SHA256SUMS.txt` 提供校验值。

- 包含 Hy-MT2-1.8B Q4_K_M、Argos 英译中、RapidOCR 中英文识字、.NET、Python 和 CPU/NVIDIA GPU 环境，无需另装环境或下载模型。
- 翻译工作台、划词翻译小窗、截图识字、深浅主题、字号调整、登录自启动、托盘及退出选择。
- Windows 10 22H2（19045）/ Windows 11 x64；当前用户安装，无需管理员权限。安装期间预留至少 15 GB 可用空间。
- 偏好设置支持自动、优先 GPU 或仅 CPU。显卡兼容情况见 README；API/在线引擎需自行配置。

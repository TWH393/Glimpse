# Glimpse 0.2.0 Preview 1 · 完整离线版

- 离线翻译统一使用 Hy-MT2，提供 CPU/NVIDIA GPU 路径，移除 Argos。
- 新增应用/全局实时字幕：本地英语识别、中文流式字幕、带时间戳的中英 TXT；支持仅 GPU 和一次自动恢复。
- 新增音视频文件转译：默认音轨、暂停继续、取消保存、中英对照 TXT。
- 修复短句空结果导致开头漏词、边界词重复提交；耗时仅在界面显示。
- 包含 .NET、翻译/语音识别模型、OCR 和 CPU/NVIDIA GPU 环境，无需另装 Python。

## 安装

下载本页 `setup.exe` 和全部 `.bin` 分卷，放在同一文件夹，运行 `setup.exe`。不要单独打开分卷，不需要合并或解压。源码压缩包不是安装包。

共 1 个安装程序和 5 个分卷，合计约 6.7 GB。发布附件另有安装说明和 `SHA256SUMS.txt`。

适用于 Windows x64；按应用或全局实时采音需要 Windows 11。GPU 路径使用 NVIDIA CUDA，其他设备可选择 CPU。保留原应用安装标识，使用相同目录覆盖安装；此版本不提供旧引擎设置迁移。
